# みえるタイマー

残り時間を赤い面で確認できる、iPhone向けのシンプルなビジュアルタイマーです。

**公開版:** https://nmrknt.github.io/mieru-timer/

## 主な機能

- 1周60分固定の文字盤
- 0〜60分を1分単位で設定
- 文字盤のタップ／ドラッグによる時間設定
- 残り時間に合わせて赤い面と先端の赤丸が滑らかに減少
- スタート、一時停止、再開、リセット
- 動作中・一時停止中の＋1分／−1分調整
- ページ再読み込みやPWA再起動後のタイマー状態復元
- 終了音の回数設定、消音、試聴
- PWAやPC／Androidブラウザからの共有
- 対応環境では画面の自動消灯を抑制
- PWA対応・オフライン動作

## 基本操作

1. 文字盤をタップ／ドラッグするか、＋／−ボタンで時間を設定します。
2. 「スタート」を押すとカウントダウンが始まります。
3. 動作中に「一時停止」を押すと停止し、「再開」で続けられます。
4. 動作中や一時停止中も、＋／−ボタンで残り時間を1分ずつ調整できます。
5. 「リセット」を押すと0分の初期状態へ戻ります。

0分ではスタートできません。スタート前に−ボタンで0分へ戻しても終了音は鳴りません。開始後、残り時間が0になると終了音が鳴ります。

終了音は1〜10回または「鳴らさない」から選択でき、「試聴」で確認できます。終了音の設定とタイマーの状態は、この端末のブラウザ内に保存されます。

## iPhoneのホーム画面へ追加

1. [公開版](https://nmrknt.github.io/mieru-timer/)をiPhoneのSafariで開きます。
2. Safariの共有ボタン（四角から上向き矢印）をタップします。
3. 「ホーム画面に追加」を選びます。
4. 右上の「追加」をタップします。
5. ホーム画面の「タイマー」アイコンから起動します。

初回に一度オンラインで開けば、以後はオフラインでも利用できます。更新後に古い画面が表示される場合は、Safariで公開URLを再読み込みしてからホーム画面版を開き直してください。

ホーム画面版では追加手順の代わりに「共有」ボタンが表示されます。対応環境ではOSの共有画面を開き、非対応環境では公開URLをクリップボードへコピーします。

## 注意事項

- 終了音を利用するには、端末の音量を確認し、「スタート」ボタンから開始してください。
- iOSの制限により、画面をロックした場合やSafariを完全に終了した場合の通知音は保証されません。
- Wake Lockに対応していない環境では、利用中でも画面が消灯することがあります。
- 本アプリは利用情報や設定時間を外部へ送信しません。

## ローカルで試す

Service Workerは `file://` では動作しないため、ローカルWebサーバー経由で開きます。

```text
python -m http.server 8000
```

このリポジトリのフォルダで実行し、ブラウザから `http://localhost:8000/` を開いてください。
